# Shahriar & Riya — Wedding Invitation (single file)

The whole invitation in one self-contained `index.html`: the CSS, the JavaScript, the wedding card image, the favicon and the calendar (.ics) download are all embedded. Open it straight in a browser or upload it anywhere; no other files are needed.

Converted from [WarRinOP/shahriar-riya-wedding](https://github.com/WarRinOP/shahriar-riya-wedding).

Still loaded from the internet: the Google Fonts (they fall back to system fonts offline) and the link-preview image (`og:image`, which must be an absolute URL anyway).

Music: the page looks for `assets/audio/bgm.mp3` next to it. With no file there, the music button stays hidden.
